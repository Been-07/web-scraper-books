# 📚 Web Scraper for Bookstore

A simple web scraper that extracts book titles and images from an online bookstore.

## Features
- Extract page title
- Extract book titles from specific HTML class
- Extract image links
- Uses requests and BeautifulSoup

## Technologies
- Python 3
- requests
- BeautifulSoup4

## Installation
```bash
pip install requests beautifulsoup4
python scraper.py
```
