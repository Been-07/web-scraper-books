# 🌐 Web Scraper

A simple yet powerful web scraper built with Python that extracts:
- Page title
- Text content from a user-specified HTML class
- Image links (supports relative URLs)

## 🚀 Features
- User inputs URL and target class name
- Extracts titles from h1/h2/h3/h4/a/span tags
- Extracts image URLs from img tags
- Converts relative URLs to absolute
- Error handling for failed requests

## 🛠️ Technologies
- Python 3.14
- Requests
- BeautifulSoup4

## 📦 Installation

```bash
pip install -r requirements.txt
```
